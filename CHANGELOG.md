# Changelog

## 0.5.2

- Reduced CPU overhead by polling mouseover at 30 Hz and rescanning UI frames every 2 seconds.
- Kept independent hide delays and fade animations for the menu, bags, quest tracker, and minimap.
- Kept support for Questie and SexyMap, including complete minimap hiding.
- Translated settings, diagnostics, documentation, and metadata to English.

This release retains the gameplay behavior and saved-setting keys of the tested 0.5.2 build.
